莓桃工作台，到底能做什么？

这里不讲长篇操作步骤，只按功能分类展示。每一块就是一个独立功能，适合老板快速盘点系统、给别人介绍产品，或者后续继续加功能时直接往对应区域补卡片。

🎨 美工端功能

从接单、顾客管理，到续期和个性化。

核心工作区
🏠

工作台总览

查看今日订单、订单数量、待办、截止提醒和当前工作状态。

🧾

订单管理

新增、修改、删除订单，可记录需求、金额、分类、状态、日期、进度和备注。

🗓️

排单管理

按照订单日期形成排单，快速查看当前和后续安排。

🌷

公开 / 隐私排单状态

美工自己设置排单状态。开启显示「🌷 公开排单」，关闭显示「🔒 隐私排单」。

状态会保存
💰

财务统计

汇总订单金额与收入信息，查看接单相关财务数据。

⏱️

工作计时

记录实际工作时间和任务用时，方便回看投入时长。

👤

顾客档案

建立独立顾客档案，管理昵称、备注、余额、绑定账号等资料。

💳

顾客余额

支持充值、扣款、余额流水；创建订单时也可以直接按订单金额扣余额。

➕

金额算式输入

余额调整支持直接输入 13+5、22+6 这类简单算式。

🔑

GC 美工通用顾客码

每位美工拥有自己的通用顾客码，顾客输入后即可绑定该美工。

🎟️

CC 顾客专属码

为具体顾客档案生成专属码，顾客输入后直接绑定指定档案。

🔗

顾客固定匿名链接

正式顾客拥有长期匿名链接，不登录也可以查看允许展示的排单。

🔗

订单专属匿名链接

未关联顾客档案的订单，可以单独生成该订单自己的匿名查看链接。

💬

美工 ↔ 顾客实时聊天

支持实时文字消息、头像、未读红点和已读状态。

🤝

美工好友

通过美工编号发送好友申请，对方接受后进入双方好友列表。

💌

美工好友聊天

好友美工之间可以实时聊天，并显示未读消息。

🔔

DDL 提醒

订单支持提前 1 天、提前 3 小时或自定义提醒时间。

🎟️

续期中心

查看到期时间、剩余时长、续期历史，并直接输入续期码。

🎨

美工版续费码

只增加使用时长，不改变当前版本，完整版账号也不会被降级。

🍓

完整版续费码

增加使用时长；当前是美工版时，会同时升级为完整版。

🕰️

旧续费码兼容

以前生成的续费码继续可用，只续时长，不改变版本。

🔒

到期只读

账号到期后历史数据仍完整保留，可查看但不能继续新增、修改或删除。

🔁

排单结束自动解绑

可设置顾客最后一笔关联订单结束后自动解除绑定。

🎨

主题美化

可自定义主色、背景、卡片、文字颜色，并使用内置主题预设。

🖼️

自定义头像

美工可设置自己的头像，并同步显示到聊天与相关页面。

📱

自定义应用图标

安装到手机主屏幕后，可使用当前账号自己的工作台图标。

🧭

自定义导航

支持修改导航名称、调整顺序、新增自己的自定义分区。

📲

手机版两种导航

支持顶部横向导航和左侧竖向导航，两种模式都支持折叠。

📝

自定义分区

可以建立素材、备注、灵感等自己的页面，并跟随账号保存。

☁️

多端云同步

同一账号在电脑、手机、平板之间同步工作台数据。

👤 顾客端功能

顾客自己的账号、排单、余额和聊天中心。

顾客使用区
🔐

顾客注册 / 登录

顾客使用自己的邮箱账号进入顾客中心。

➕

绑定美工

使用 GC 通用顾客码或 CC 顾客专属码添加美工。

👩‍🎨

多美工管理

一个顾客账号可以同时绑定多位不同美工，数据彼此独立。

🗓️

我的排单

查看自己在不同美工处对应的订单和排单信息。

🌷

排单状态

查看美工当前显示的是「公开排单」还是「隐私排单」。

💰

我的余额

查看自己在每位美工处的余额和历史流水。

💬

联系美工

与已经绑定的美工进行实时聊天，支持未读和已读状态。

🖼️

顾客头像

头像由顾客本人修改，美工端只能查看，不能替顾客更改。

✏️

顾客显示名称

顾客可以设置自己的名字，并同步显示到美工端和聊天。

📝

给美工写私人备注

可给不同美工添加仅自己可见的备注，不会发送给对方。

🎨

顾客端美化

可修改主色、背景、卡片、文字颜色和“我的排单”图标。

🔗

免登录匿名查看

不想注册时，也可以直接通过美工发送的匿名链接查看允许公开的信息。

👑 Owner 后台功能

老板用于账号、邀请码、续费和系统运营管理。

仅 Owner
👥

账号管理

查看系统中的美工账号和顾客账号。

🔎

搜索用户

按账号信息快速查找对应用户。

🏷️

管理员备注

给账号写仅 Owner 自己可见的备注，例如微信名、昵称或身份说明。

⏳

直接增加使用时间

通过账号 UUID 直接增加美工使用天数。

♾️

永久权限

将指定美工账号直接设为永久使用。

🎫

生成注册邀请码

创建新的美工注册邀请码，注册逻辑与续费逻辑相互独立。

🎟️

生成续费邀请码

支持 7 天、30 天、90 天、365 天和永久续费。

🎨

续费版本选择

生成续费码时可选择「🎨 美工版」或「🍓 完整版」。

🔢

单次 / 多次邀请码

邀请码可以设置仅使用一次，也可以允许多个账号使用。

📊

邀请码使用次数

查看邀请码已经使用多少次、最大次数和当前状态。

🟢

启用 / 停用邀请码

可随时关闭某个邀请码，使其立即停止使用。

📜

权限调整历史

查看之前对账号进行的加时、永久权限等调整记录。

🚧

全面暂停普通美工端

一键暂停普通美工进入工作台，Owner 自己不受影响。

📡

系统容量监控

查看活跃账号、实时连接等系统使用规模。

💬

聊天容量监控

查看聊天消息数量和当前消息使用量。

🎨

后台主题配色

Owner 管理端拥有独立主题和颜色设置。

🔐 系统与安全能力

用户平时看不到，但一直在后台工作的基础能力。

系统底层
🛡️

账号数据隔离

每个账号只能读取和修改自己有权限访问的数据。

🔒

服务端到期只读

不是只把按钮变灰，数据库层也会阻止到期美工继续写数据。

👥

顾客 / 美工关系隔离

顾客只能看到已绑定美工，美工只能管理自己的顾客关系。

💾

数据长期保留

到期、续期和版本升级都不会删除订单、财务、顾客、聊天或好友数据。

🔄

Realtime 实时同步

聊天、头像、部分状态变化可在不同设备之间及时更新。

☁️

Supabase 云同步

工作台数据保存在云端，并保留本地缓存作为临时兜底。

📲

PWA 安装

支持添加到 iPhone、iPad 和 Android 主屏幕，像独立应用一样打开。

🔔

系统通知

支持浏览器 / 手机系统通知和订单截止提醒。

🔑

邮箱密码账号

支持注册、登录、忘记密码、邮件重置密码和登录后修改密码。

📤

数据导出

支持导出 JSON / CSV，方便自行备份或整理。

📖

内置功能总览入口

美工端多个位置可以直接打开本页面，随时查看当前系统有哪些能力。

🧹

旧权限逻辑清理

已清理旧注册 Trigger 和旧 Owner-only 权限限制，避免历史逻辑重新干扰新系统。

版本说明：现在系统已经支持美工版 / 完整版续费规则和账号版本字段。后续如果需要让两个版本拥有不同的具体功能，可以继续在对应功能卡片上加「美工版 / 完整版」标签。
