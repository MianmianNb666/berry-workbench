先分清 3 个东西，不然后面很容易串线 🎟️

它们长得都像“入口”，但用途完全不同。

① 美工邀请码

BERRY-...

给美工自己注册或续期工作台使用。顾客不需要它。

② 美工专属顾客码

GC-...

美工发给顾客。顾客注册/登录顾客端后输入它，就能解锁这位美工。一个顾客可以解锁多个美工。

③ 匿名链接

customer.html?share=SH-...

不用注册、不用登录。有顾客档案的顾客一人一条长期链接；未建档顾客才是一单一条链接。

最重要：美工邀请码 ≠ 顾客码 ≠ 匿名链接。美工邀请码管“美工能不能用工作台”，顾客码管“顾客账号能不能解锁某位美工”，匿名链接管“无需登录直接看排单”。

美工 ↔ 顾客到底怎么连接？ 🔗

有 3 种常用场景。选对场景以后，整个系统会很顺。

场景 A：顾客愿意注册顾客端账号

建立美工与顾客的授权关系
1

美工找到顾客码

进入「我的 → 顾客端」，复制“专属顾客码”或“顾客入口”。

美工端 → 我的 → 顾客端 → 复制顾客码
2

顾客注册或登录

第一次注册必须带至少一位美工的 GC 码。已经有顾客账号时，进入「我的 → 添加美工」输入新的 GC 码即可。

顾客端 → 我的 → ＋ 添加美工 → 输入 GC-...
3

一位顾客可以连接多个美工

每位美工都需要各自的 GC 码。拿到 A 的码只会解锁 A，不会看到 B。

如果顾客使用登录模式，输入美工提供的 GC 顾客码完成绑定后，就可以在自己的顾客账号里查看这位美工。

美工端详细教程 🎨

从第一次注册到完整接单流程。

第一次注册

输入邮箱、密码和美工邀请码。邀请码只在第一次注册需要。之后正常登录不需要邀请码。

续期

使用期快到时会提前两天弹窗提醒。到期后数据不会删除，但美工端会进入只读模式。

1

先建立有顾客档案的顾客

进入「顾客」页面，点“＋ 添加顾客”。可以设置顾客昵称、美工备注、关联顾客端账号和余额。

美工端 → 顾客 → ＋ 添加顾客
2

给顾客充值 / 加预算

进入顾客管理，填写“调整金额”和说明，点击“增加余额”。每一笔都会形成流水，不会覆盖历史。

3

新建需求 / 订单

点击“新增需求”。填写需求名称、金额、状态、日期、分类、进度和备注。如果这位顾客已经建立档案，在“用户 / 顾客”里直接选择她；如果没有建立顾客档案，就保持不关联。

4

保存订单时直接扣顾客余额

选择有顾客档案的顾客后，“保存订单时直接扣除本单金额”会自动可用。系统会显示扣费后余额。如果余额不足，会拦住，不会让余额直接变成负数。

5

分享给顾客

有顾客档案的顾客使用固定的“顾客匿名链接”；没有顾客档案的订单使用该订单自己的专属匿名链接。如果顾客有账号，也可以让她用 GC 顾客码登录顾客端。

6

更新进度

订单状态可切换为“待处理 / 进行中 / 待付款 / 已完成”。顾客查看端读取的是公开进度信息，不会把你的美工备注和工作台原始数据暴露出去。

7

DDL 与系统通知

订单可以设置提前 1 天、提前 3 小时或自定义提醒。手机安装到主屏幕后允许通知，提醒体验最好。

8

个性化

可以改应用名称、通知名称、头像、应用图标、导航名称、导航排序、显示风格和主题颜色。设置会跟随账号同步。

顾客端详细教程 👤

顾客可以选择“登录账号模式”或“匿名链接模式”。

登录账号模式

1

第一次注册

输入邮箱、密码和美工发来的 GC 顾客码。没有顾客码不能注册进入对应美工。

2

添加第二位、第三位美工

一个顾客账号可以对应多个美工。进入「我的 → ＋ 添加美工」，输入另一位美工自己的 GC 码即可。

3

查看不同美工

「我的美工」会把已解锁的美工分别列出来。余额、排单和后续订单都按美工分开，不会串账。

4

查看余额明细

如果美工为顾客建立了余额账本，顾客可以看到当前余额和每一笔增加 / 扣费记录，但不能自己修改。

5

自定义顾客端

设置里可以改主色、背景、卡片、文字颜色，也可以把“我的排单”旁边的小草莓 🍓 换成自己的 emoji。

匿名链接模式

不需要邮箱、不需要密码、不需要注册。打开美工发来的匿名链接就能查看。有顾客档案时使用固定链接；没有建立顾客档案时，每笔订单使用自己的专属链接。

匿名入口到底会显示什么？ 🔐

会显示

美工名称、顾客昵称、订单名称、分类、状态、完成进度、开始日期、截止日期和更新时间。

不会显示

订单金额、顾客余额、联系方式、美工美工备注、其他顾客的订单、工作台里的其他数据。

匿名链接可以直接打开查看排单，不需要注册或登录。请保存好自己的链接，不要随意转发给其他人。

余额和订单扣费 💰

1

先给顾客余额

顾客管理里增加余额，例如 +¥300，并填写“预存 / 充值”等说明。

2

新单选择顾客

新建订单时选择这个有顾客档案的顾客，系统会显示她现在还有多少余额。

3

保存时自动扣费

订单 ¥80，余额 ¥300，保存后会自动记一笔 -¥80 流水，剩余 ¥220。

4

删除已扣费订单

系统会提醒“删除订单不会自动退款”。这样可以避免误删订单导致账本自己倒流。

DDL 提醒和通知 🔔

订单提醒

可以同时开启提前 1 天、提前 3 小时、自定义提醒。系统会按你设置的时间推送。

收不到通知怎么办

先确认已经把工作台安装到主屏幕，再确认浏览器 / 系统通知权限允许。Android 还需要检查电池优化有没有限制 Chrome 或工作台。

安装到手机主屏幕 📲

iPhone / iPad

1. 用 Safari 打开工作台。
2. 点底部“分享”。
3. 往下找到“添加到主屏幕”。
4. 确认名称后添加。
5. 以后从桌面图标打开，再去设置里开启系统通知。

Android

1. 建议用 Chrome 打开。
2. 点右上角菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 从桌面图标重新打开。
5. 允许通知；如果提醒迟到，再检查电池优化。

美工使用期到期会发生什么？ ⏳

不会发生的事

不会删除数据，不会把顾客踢掉，不会让已经生成的顾客匿名链接失效。

会发生的事

美工端到期后仍可以登录查看已有内容，但不能继续新增或修改内容。续期后即可恢复正常使用。

续期成功后会恢复编辑权限。到期前 48 小时内，系统会弹窗提醒续期。

常见问题 🧩

顾客一定要注册账号吗？

不用。有顾客档案的顾客可以只用自己的固定匿名链接。注册账号的好处是一个账号可以统一管理多个美工。

一个顾客能绑定多个美工吗？

可以。每位美工需要单独的 GC 顾客码。不同美工的余额和数据是分开的。

有顾客档案后，每个订单都要重新发链接吗？

不用。她只有一条固定匿名链接。以后新订单只要关联到她，就会自动出现。

什么时候使用“一单一链接”？

当这笔订单没有关联顾客档案时，就使用该订单自己的专属匿名链接。

顾客能看到美工美工备注吗？

匿名查看不会。公开读取只返回清洗后的订单字段。

美工到期后顾客还能看吗？

可以。已有的顾客端关系和匿名链接继续有效，美工端只是不能继续写入。
